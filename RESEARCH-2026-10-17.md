## 0. Executive summary (TL;DR)

1. **The wall is the IP, not the fingerprint.** Every anti-bot vendor
   (Akamai, DataDome, Cloudflare, AWS WAF) checks IP reputation *first*;
   TLS/JA3/JA4 and HTTP/2 fingerprints are software-solvable but only upgrade
   you from "hard block" to "challenge loop" on a datacenter IP.
2. **Our blocked sites are mostly Akamai, not Cloudflare** (first-party
   forensics, this machine): Myntra, Nykaa, Ajio, JioMart, Pinterest, Meesho
   → Akamai (`Akamai-GRN`, `_abck`, `bm_sz`, `errors.edgesuite.net`).
   Etsy → DataDome. TataCliq → Cloudflare. Snapdeal → CloudFront.
   Facebook → Meta's own edge. Amazon (IN) → AWS WAF challenge.
   ⇒ Cloudflare-specific tooling (FlareSolverr, cloudscraper, Turnstile
   solvers) is **irrelevant** for our hardest targets.
3. **This machine's own IP passes several of the "blocked" sites** with
   TLS impersonation (curl_cffi, Chrome print): Myntra, Nykaa, Snapdeal,
   Pinterest, Flipkart — full pages (119 KB – 1.35 MB). Meesho answers 200
   (small body). Etsy stays 403 even direct (DataDome — needs residential
   or the Etsy Open API). Amazon answers its WAF challenge either way.
4. **Zero-cost path that actually works for the hard sites** (researched,
   not yet wired):
   * Stack vendor free tiers: **Bright Data Web Unlocker 5,000 req/mo free**
     + **ZenRows 5,000 credits/mo free** + **Scrape.do 1,000/mo free**.
     Only friction: Bright Data KYC (≤3 days).
   * Official/free APIs where they exist: **Flipkart Affiliate API (free,
     product search!)**, **Shopify Storefront GraphQL (tokenless)**, Etsy
     Open API (personal app), eBay Browse API (sandbox free), YouTube Data
     API, Reddit OAuth (non-commercial).
5. **Cheapest paid unlock:** **DataImpulse $5 → 5 GB residential,
   never-expires, India supported** (never top-ups min $50; mobile $2/GB
   intro). For managed bypass: **Scrapfly $30/mo ≈ 7,000 hard pages** or
   **Scrape.do $29/mo (250 K credits, pay-on-success)**.
6. **Next best engineering step (unproven but evidence-backed):** Akamai
   `_abck` cookie-mint → HTTP replay: let a real browser (nodriver/Camoufox)
   solve Akamai once per domain, export cookies, then replay with curl_cffi
   using the same UA + sticky IP. Recommended tool order for browsers:
   **nodriver > camoufox > patchright > Playwright** (28/31 vs 25/31
   vs 25/31 vs baseline).

### 2.4 Service stability incident (worth noting)

The MCP-started service (PID 17108) died ~2–3 min after start during the
initial verification phase, with buffered logs lost (empty log, empty
session dir, no Windows crash event ⇒ clean-ish Python exit or external
termination, no traceback captured). The debug restart (unbuffered,
`-u`, output captured to `output/service_debug.*.log`) started fine and is
being monitored; if it dies again the traceback is now visible.

**Fix status (same day, round 3):** addressed. The pool refresh loop is now
crash-isolated — a failing cycle logs its traceback and retries instead of
leaving the pool frozen — and `faulthandler` is enabled at startup with
line-buffered stdout/stderr, so any hard crash leaves a Python stack even
when the service is started without `-u`. See README "Stability hardening"
and `IP-ENGINE-INTEGRATION.md`.

### 2.6 Free "residential" proxies are hijacked devices (report)

A dedicated report documents, from FBI / Google / BitSight / NDSS sources, that
free-list "residential" proxies are mostly **hijacked devices** (AVrecon/
SocksEscort ~369k routers; IPIDEA SDKs; ~15% active-malware, ~50% for IPIDEA),
plus honeypots and content-manipulating proxies — and that the only
**consent-based free** networks are **Tor / I2P / Snowflake** (not residential
proxy pools, and blocked by the hard targets). See `HIJACKED-PROXY-RESEARCH.md`.

## 3. Detection layers — what software can and cannot fix

| Layer | Seen at | Software-solvable? |
|---|---|---|
| JA3/JA4 TLS fingerprint | CF, Akamai, DataDome | ✅ curl_cffi / tls-client / curl-impersonate |
| HTTP/2 frame ordering | CF, Akamai | ✅ same tools |
| Header order/consistency | All | ✅ |
| JS fingerprint (canvas/WebGL/nav/audio) | All | ⚠️ partially — nodriver / Camoufox |
| CDP/automation tell | CF, Akamai | ⚠️ partially — nodriver passes where Playwright forks fail |
| Akamai sensor (`_abck`, `bm_sz`) | Akamai sites | ⚠️ partially — real browser mints it; HTTP replay then works |
| AWS WAF challenge (Amazon 202) | Amazon | ⚠️ JS challenge can pass with warm-up (~82% after 7 warm-up steps, n=135, vendor-adjacent data) |
| **IP reputation (datacenter ASN)** | All | ❌ **only the IP class fixes this** |
| Behaviour/session scoring | All | ⚠️ pacing, warm-up, sticky sessions |

## 7. Recommended implementation backlog (for this project)

Ranked by (impact ÷ effort), all aligned with existing architecture:

1. **curl_cffi HTTP backend** (`--http-impersonate chrome`) — swap/augment the
   aiohttp fetch path for target fetches. Cheap win vs JA3-sensitive edges;
   matters even on pool IPs (upgrade 403-hard → challenge-soft), and big for
   direct fetches. Low effort (one adapter class).
2. **Direct-route option** — allow `/fetch` (opt-in, rate-limited) to go
   *without* proxy for domains where the caller's own IP is best (India
   e-com). Massive win discovered today: Myntra/Nykaa/Snapdeal/Pinterest/
   Flipkart full pages from this machine, no proxy. Medium effort, high value.
3. **Unlock-API adapter** — if `UNLOCK_API_URL` + key set (ScraperAPI/ZenRows/
   Scrape.do/BD-compatible), route flagged domains through it. Enables the
   $0 free-tier stack without touching callers. Medium effort.
4. **Akamai mint→replay prototype** — `akamai_warm.py`: nodriver/camoufox
   opens one category page per Akamai domain, exports `_abck`/`bm_sz`
   cookies + UA; service replays with curl_cffi on sticky IP. Research-backed
   (TWS Club #113 pattern), medium-high effort, prototype first.
5. **nodriver as preferred browser engine** — add to `stealth_browser.py`
   behind the same interface (install optional). Low effort, best stealth
   score (28/31).
6. **Docs/examples**: Flipkart Affiliate API sample, Shopify Storefront
   sample, Keepa/SerpAPI notes, social API table. Low effort, in this repo
   as `examples/` snippets.
